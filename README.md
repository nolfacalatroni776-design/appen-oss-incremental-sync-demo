# 京数·通用能力数据服务平台 · S3 协议 增量同步 Demo

公开访问：https://nolfacalatroni776-design.github.io/appen-oss-incremental-sync-demo/

临时交互原型，使用样例数据，刷新恢复初始状态。

桶信息由上游系统传入，保存在项目后端。同步内容固定为标注结果文件与质检结果文件。增量在平台侧按成果版本及成功记录判断，不要求读取客户桶。

记录与详情提供查询、分页、明细和手动重试；详情仅有“数据明细”“文件清单”两个页签，重试入口为“重试失败数据”；本期不展示文件大小、耗时，不提供记录或清单的下载导出，不自动重试。

数据中心支持按“同步中”筛选，排队和执行中的增量数据显示该状态；单条完成后立即显示“已同步”或“同步失败”，跳过及排除项保持原状态。

页面不连接实际 S3 或生产接口。
